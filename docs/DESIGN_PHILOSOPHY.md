## 一、元原则

### δS=0 为元物理层唯一生成原理

> 一切物理结构从作用量变分涌现：$$δS=0 \implies \text{运动方程 (Euler-Lagrange)} / \text{时空曲率 (Hilbert)} / \text{量子振幅 (Path Integral)}$$

- **δS=0 是唯一生成原理**：action→force / action→spacetime_curvature / action→quantum_amplitude 是脑内因果方向的唯一来源
- **Noether / Locality / Entropy 是派生**：只容纳可严格证明的定理，不当作独立生成源
- 因果方向三态判定（causal/forbidden/unverified）唯一依据 δS=0 变分；三类伪因果（词共现、代数变形、双向）被逐层堵死，代数变形产物永远进不了因果层

### 喂种子不喂果子

> 喂种子 = 给知识 + 方法论（变分法/诺特定理/群论）。不喂果子 = 不硬编码结论、不搭管道。脑自己长结构 + 能力。

判定标准：新增代码是不是在「接线」（把 A 的输出手动连到 B 的输入，如挂账字段、手动 curiosity 注入、中间状态追踪）？是 → 应该改成规则（奖励规则/学习规则），让行为策略自组织涌现。只有奖励/学习/权重规则可以动，行为管道不能搭。

### 容量不给方法

人为调参数 = 方法。扩充探索空间 = 容量。

| 容量（我们做的） | 方法（我们不做的） |
|:-|:-|
| 知识注入 1187 因果方向 + 混沌脑随机边 | 标记"这条边是主干道" |
| 突触补路给细胞 top-3 候选 | 告诉细胞"force 比 eta 重要" |
| 私有突触让细胞自己建权重 | 预设分类器或标签 |
| sympy 引擎给所有概念两两推导 | 限制推导只走已知路径 |

分类不来自标签，来自**连接模式**。mass 出度高 — 不是我们说的，是图自己告诉脑的。

### 噪声创造路径，结构决定结果

> 细胞走得太确定 → 只踩热门边 → 大量图边从未被触碰 → 突触无法生长。
> 加噪声（ε-贪心探索）→ 细胞随机绕路 → 踩到新边 → Hebbian/LTP 自然选出有用的。
> 不用告诉脑走哪条路。结构（LTP、dopamine、BCM、LTD）会筛掉噪声里无用的，留下有用的。

这是"只给容量不给方法"在行走策略上的直接推论。ε-贪心的 ε 本身也是容量的一个维度：随机度可以衰减，但不能为零。**没有噪声就没有新路径，没有结构就分不出有用路径。**

| 噪声的作用 | 结构的作用 |
|:-|:-|
| 随机选边（ε=0.3→0.15） | Hebbian 强化重走的边 |
| 覆盖权重偏见盲区 | BCM 抑制过强边 |
| 让更多图边有机会被触碰 | LTD 淘汰从未被重走的边 |
| 增加神经元重叠概率 | dopamine 标记有结果的路径 |

这解释了一个深层事实：**313K 图边 + 无噪声行走 → 99.84% 的边永远不会被第二次踩到 → 突触永远长不出来。** 加噪声不是锦上添花，是让"结构筛选"这个基本机制有东西可筛。

### 自由能极小化 = 惊奇度驱动

```
预测模型猜下一步 → 实际不同 → prediction_error (惊奇)
    ↓
intrinsic_curiosity += error → 驱动走向未知
    ↓
学懂了 → 预测变准 → 误差衰减 → 好奇淡出 → 漂移找下一个
```

暂时放大误差就是为了最终消灭它——自由能原理的自然实现。

### 动机链与 RPE 隐式预言回路

```
惊奇 → 好奇 → 探索 → 实验/推导 → 消化(预测落空→命中) → 奖励
```

- **惊奇 = 信号，不是奖励**；奖励在**学习完成时**兑现（RPE: δ = R − V，学会后误差消失——不是惊奇本身）
- **学会奖励判据（v3，刷分三轮收敛）**：主流预测翻转 + 证据门槛（prev_predicted 非空）+ 自环不奖——只发一次，循环走位刷不了分
- **已验证关系 = 低探索价值**：成功推导的对 coincidence 减半（好奇心衰减），让未探索的对上位
- **RPE 隐式预言回路**：预测是行走的**副产物**，不建显式预言生成器（那是给方法，错）；只有落空才产生信号（+2.0 意外命中 / 0 兑现 / 0 落空），落空 + EIG≥1.6 → 高价值发现
- **δS=0 管因果（语法），预测管价值（语用）**：进化尺度的预测是 δS=0 的结果投影，个体尺度的预测是机制动力

实现准则：只改规则让闭环涌现，禁手动接线/挂账/注入。惊奇→好奇→探索→消化的每一步都必须是已有机制的自然组合，新增代码只允许是奖励规则或学习规则。

### 自然选择优于行政命令

- 加权走边：白名单域优先，但不硬砍噪声边，让它们自然枯萎
- s 值三体：预测强度 + 惊奇度 + 学习速率一体化
- 杏仁核绕死路：derive 失败 → 后向抑制 → 自动绕道
- 四机制垃圾免疫：代谢成本(A) + 相干场(B) + 用进废退(C) + 晋升窗口(D)

### 拓扑即认知

认知操作不是外部函数调用，是**图上游走**。`_trace_to_action` 沿边从矛盾节点走到 action——这个游走本身就是推理。方法论不在代码里，在拓扑里。

## 二、结构约束：一致性逼迫

> 量子场论的深刻洞察：$$\text{局域对称性} \implies \text{规范场} \implies \text{粒子}$$
> 对称性是**约束**，不是优化目标。光子不是"慢慢优化出来的"——U(1) 局域对称性一写上，光子就被**逼出来了**。
>
> 费曼脑的结构遵循同构逻辑：$$\text{一致性约束} \implies \text{补边} \implies \text{涌现结构}$$


### 自由能是动力学，不是结构约束

自由能极小化管的是**细胞往哪走、走多快**——这是动力学，是优化。它不回答"什么结构必须存在"。

QFT 里，自由能极小化管的是场的**运动方程**（Euler-Lagrange），不管场的**存在性**。规范场 A_μ 的存在性来自局域对称性——那是约束，不是优化。

**脑的结构不是优化出来的。是被一致性逼出来的。**

### 四种结构约束

| 约束 | 逼出的结构 | QFT 类比 |
|------|-----------|----------|
| **因果闭包**：每个效应节点有 cause-chain 回到 tier≤1 | WHY 溯源 + emergent 捷径 | U(1) → 光子 |
| **概念规范不变性**：同一物理在不同框架下等价 | 跨域桥（mass↔GR, 量子↔几何） | SU(2) → W/Z |
| **VSA 代数闭包**：bind/unbind 在图上可表示 | composed 边 | 张量积结构 |
| **拓扑一致性**：三元闭包、循环消解 | hebbian 捷径 | 曲率/挠率约束 |

### 因果闭包 — 最核心的约束

> **每个登记在案的效应，必须有可达的因果链追溯到已知原理（tier ≤ 1）。否则图不自洽。**

这不是优化目标——图不满足就**不自洽**。就像 QFT 里如果没有 A_μ，导数项在局域变换下多出一项，拉氏量直接不自洽。

| | QFT | 费曼脑 |
|---|---|---|
| **约束** | 拉氏量在局域相位变换下不变 | 每个效应节点有 cause-chain 回到 tier≤1 |
| **不自洽后果** | 没有 A_μ → 导数变换多出一项 | 没有补边 → 效应节点悬挂，因果链断裂 |
| **被逼出的结构** | 规范场 A_μ | WHY 溯源路径 + emergent 边 |
| **结构不是选的** | 是数学逼的 | 是因果一致性逼的 |

**1-形式 A_μ 是导数协变性的代价。emergent 边是因果闭包的代价。**

### 概念规范不变性

从"力 = 质量 × 加速度"和"作用量变分 = 0"描述同一件事——图上这两个视角**必须**有路径连通。不通不是"还没学到"，是图在逻辑上不自洽。

这个约束逼出**跨域桥**——就像 SU(2) 逼出 W/Z 玻色子。mass 枢纽（力学↔GR↔量子↔电磁）的大量 emergent 边，不是"关联多了自动长出来"，是**概念规范不变性逼出来的**。

### 对脑演化的意义

```
关联涌现（coincidence → emergent）：这两个东西经常一起出现
推导涌现（derive → math_verified）：这个结构是那条规则的必然代价
```

前者是现象学，后者是第一性原理。希格斯场在真空中自发破缺——不是"有人选了有质量"，而是"没有质量的对称解是不稳定的"。mc² 不是被放进来的，是真空不稳定性**逼**出来的。费曼脑的 hub 不是被标记的，是图自洽性**逼**出来的。

## 四、发现引擎

### derive 纯 sympy，零 LLM

568 定律 / 1187 因果方向覆盖力学→电磁→热力→量子→GR→统计→核物理→粒子→流体→等离子→天体→光学→相对论→原子→固态→量子信息→场论。

输入端不受限。两个概念名 → sympy 求解 → 通过则验证边。solve 有 SIGALRM 10s 硬超时保护（sympy 对特定表达式可能无限循环，try/except 捕获不了）。**注意：derive 产物是代数变形（解方程），零新信息——它做的是「一致性检查」，不是「发现」。** 多路径殊途同归（conf 0.95）有验证价值，单桥链（conf 0.65）跨方程符号身份可疑，降权待验。

### coincidence → emergent

细胞反复走 A→B 和 B→C → coincidence(A,C) 累积 → threshold 触发 → 长出 emergent 边。当前 1,194 条 emergent，181K coincidence 对。

hub_bonus：所有可信域计入枢纽度 → 物理节点门槛降低 → emergent 优先长在物理核心。

### 0LLM 纯符号验证（arXiv 摄入已停用）

2026-08 起 arXiv 文本摄入 + LLM 论文校验全部下线：词共现伪因果曾污染因果图（63 条残留已清），token 级 LLM 残留黑名单 + physics_passed 闸门加严。因果方向唯一依据 δS=0 变分（定律库 causal_direction / forbidden_directions），代数变形产物走 `math_verified` 域，永远进不了因果层（tier2 需 δS=0 变分因果通道）。
