# 深刻理解的神经基础与费曼脑架构映射

> 核心答案：不只是"连接更多"，而是"连接更高效、更精确、且能耗更低"。
> 新手大脑像"荆棘丛"，深刻理解者的大脑像"高速公路网"。

## 四大原则与架构对应

### 1. 神经修剪（变少） — 只保留主干道

**生物原理**：深刻理解触发突触修剪，清除无关、冗余、错误的连接。专家解题时大脑整体活跃度反而低于新手——不瞎忙，只调关键脑区。

**费曼脑实现**：
- **ABCD 四机制垃圾免疫** (`synaptic_layer.py`)：代谢成本（A）、相干场（B）、用进废退（C）、晋升窗口（D）四重自动衰减
- **白名单过滤** (`VSAGraph._clean_snapshot_data`)：只保留 9 个经过证明的域入图
- **加权走边** (`evolvable_cell._step_forward`)：白名单域 EIG×2，非白名单不被删但少走，自然枯萎

**设计原则**：不做"垃圾检测器"。创造垃圾无法生存的生态——不删边，让没用的自然饿死。

### 2. 髓鞘化（变快） — 高速公路

**生物原理**：高频使用的核心通路被髓鞘包裹，信号传输速度提升近百倍。专家能瞬间"直觉性"反应。

**费曼脑实现**：
- **路径强化** (`_handle_derive`)：derive 成功 → 全路径 s 值 +0.3
- **s 值累积** (`synaptic_layer.strengthen`)：每次 walk 穿过 → s 值增长 → 下个细胞更大概率走
- **coincidence → emergent shortcuts**：经常共现的边自动长捷径

**设计原则**：羊肠小道 → 高速公路。不是我们指定"这是主干道"，是细胞走多了自己变粗。

### 3. 多脑区协同（变强） — 大合唱

**生物原理**：物理距离较远的脑区建立低频振荡同步。不同维度同时调动——逻辑、空间、直觉形成"整体通感"。

**费曼脑实现**：
- **coincidence 聚类**：跨域概念同时激活 → 聚类
- **emergent shortcuts**：A 域和 C 域节点经常一起出现 → Hebbian 捷径 A→C
- **跨域 walk**：mass（mechanics）→ spacetime_curvature（GR）→ action（变分）

**设计原则**：不是预设跨域连接。细胞自己走出 mechanics→quantum→GR 的路径，coincidence 自己聚团。

### 4. 预测编码（变准） — 脑补

**生物原理**：大脑建精准"预测模型"，极少外部线索就能自动推演后续发展。

**费曼脑实现**：
- **cell walk + INTERVENE**：细胞 walk 预测 A→B，INTERVENE 反事实验证
- **WHY 溯源**：矛盾触发 WHY → 沿因果图回溯 → 找根因
- **derive 推导**：sympy 从已知公式推导未知关系——纯数学预测

**设计原则**：预测→验证→强化 是自然闭环。不是"教"脑预测什么，是让它自己预测，验证结果自然强化或削弱。

## 设计铁律

**"只给容量，不给方法"**：
- ✅ 给更多细胞（种子）、给边的自然选择倾向（加权）、给强化机制（路径髓鞘化）
- ❌ 不指定"这条路重要"、"这个概念该学"、"这个边该删"
- ✅ 做减法靠自然选择：不走的路自然 s↓ → 衰减 → 消失
- ❌ 不做减法靠行政命令：不按白名单直接删除运行时的边

**"理解"是副作用**：
- 系统不追求"理解"，理解的四个维度（修剪/髓鞘化/协同/预测）是架构自然运行的结果
- 图变密≠理解深。一两条能 sympy 严格推导 + 跨域共振的边 > 一万条随机连接
